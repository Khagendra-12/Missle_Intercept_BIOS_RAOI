# Assumptions / implementation decisions
1. `10^100` is represented as the exact arbitrary-precision integer `10**100` only as a bound/label. No range, array, or loop scales with it.
2. Civilization cells are 2D (`i,j`) and layers are discrete integer indices.
3. Coordinates: 1 cell unit = 1 km; cell centers are `(i+0.5,j+0.5)`.
4. Hostility is procedurally generated by keyed hash-based randomness; y-only normalized matching is exposed as `hostility_match`.
5. GRF is sampled lazily through random Fourier features; weather is never stored for the whole universe.
6. Missile max range is 20 km; interceptor detection range 12 km; interception radius 3 m.
7. Interceptor top speed is configurable (default 75 m/s; set 95 through API request).
8. All engagements are generated on demand. Monte Carlo runs are sequential.
9. The missile interception-avoidance / evasion system is deliberately omitted.
10. This is a scaffold suitable for integration and experimentation, not a validated flight-dynamics model. Tune parameters, units, launch profiles, APN, and success definitions with domain experts before making scientific claims.
11. Layer spacing currently assumed 1 km per layer for local engagements. If layer spacing is intended to be another value, set `layer_spacing_km` and update target z conversion in `engagement.py`.
